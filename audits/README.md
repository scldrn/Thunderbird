# Repository audits

Dated migration, Markdown review and cleanup evidence. Each report is a snapshot with its own stated scope; absence from a historical manifest does not prove current absence.

`recovery_attempt_2026-11-11.md` records the final recovery attempt and the scope of files excluded from the active inventory.

See [`../docs/repository_organization.md`](../docs/repository_organization.md) for placement and naming rules.

`historical_migration_status_2026-11-11.json` preserves an obsolete migration snapshot; use the dated recovery and cleanup audits rather than its counts.

`readiness_2026-11-11.md` records selected environment, CAD and provenance checks and their limits.
